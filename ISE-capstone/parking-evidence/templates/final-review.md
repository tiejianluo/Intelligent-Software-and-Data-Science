## Suggested final presentation sequence

1. Show the source and evidence that made the problem worth investigating.
2. Explain one fee rule and a counterexample by hand.
3. Trace one user operation through architecture, code, transaction and test.
4. Demonstrate pending payment, denial and recovery, not only success.
5. Show actual before/after evidence including one result that challenged the claim.
6. Explain the value decision, remaining limitations, next policy change and debt.
7. Each student answers an unfamiliar variation without delegating the reasoning.
