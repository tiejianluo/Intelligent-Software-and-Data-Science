# Evidence templates

Copy these into your A1–A6 evidence directories. Blank or `null` values mean **not yet measured**, never zero or a successful result.

| Template | Purpose | Used in |
| --- | --- | --- |
| [Evidence ledger](evidence-ledger.csv) | Provenance, permission, support and contradiction | A1; maintained throughout |
| [AI-use log](ai-use-log.csv) | Prompt, advice, student verification and rejected candidates | All six tasks |
| [Task attempt and walkthrough](student-attempt.md) | Prior reasoning, peer challenge, explain-back and transfer | All six tasks |
| [Experiment](experiment.md) | Freeze claim/oracle/workload/stopping rule before a change | A5–A6 |
| [Run manifest](run-manifest.json) | Exact revision/environment/command/results | A3–A6 |
| [Observation rows](observations.csv) | Raw task outcomes, not averages alone | A1, A4, A6 |
| [Value worksheet](value-evaluation.md) | Compare outcomes and cost without invented savings | A1, A6 |
| [ADR and debt](decision-and-debt.md) | Alternatives, consequence, revisit/retire triggers | A3–A6 |
| [Final review](final-review.md) | Evidence index and individual contribution | Each submission; final synthesis in A6 |

Do not publish identifying participant information. A pseudonymous ID is still controlled research data if it can be linked to a person. Keep consent/linkage records separately according to the approved study protocol.
