# ISE capstone teaching examples

- [Parking Evidence: an A1–A6 capstone](parking-evidence/README.md) — an English, six-task walkthrough from a handwritten parking proposal to a verifiable, evolvable service. Includes Codex task contracts, worked design decisions, a runnable fee-rule seed, and evidence templates.

These materials are instructor demonstrations. Students must produce their own observations, implementation, experiments, and explain-back records.
